# Malaysia Property Investment Website Structure

## Website Navigation & Layout

### Header
- Logo: "PropertyMalaysia" or similar
- Navigation Menu:
  - Home
  - Education
  - Property Listings
  - Investment Recommendations
  - About
  - Contact

### Main Sections

#### 1. Hero Section
- Compelling headline about Malaysian property investment
- Background image of modern Malaysian skyline or property
- Call-to-action buttons

#### 2. Education Section
- **Investment Criteria**
  - For Investment vs Own Stay
  - 7 Key Criteria with explanations and examples
  - Interactive elements to help users understand each criterion
- **Terminologies**
  - Glossary of property investment terms
  - Searchable and categorized
- **Financing Options**
  - Types of loans available
  - Comparison tables
  - Calculator tools

#### 3. Property Listings Section
- **Search & Filter Interface**
  - Property Type: Apartment, Condominium, Landed Bungalow, Landed Semi-detached, Landed Terrace, Land
  - Location: City, State dropdown
  - Status: New Launch, Completed, Sub-sales
  - Size: sq ft, sq meter, acres
  - Price Range
- **Property Cards**
  - Property image
  - Price, location, size
  - Property type and status
  - Key details
- **Map View**
  - Interactive map showing property locations

#### 4. Weekly Investment Recommendations
- **Featured Properties**
  - Curated selection with analysis
  - Investment potential ratings
  - Market insights
- **Market Trends**
  - Charts and graphs
  - Analysis and commentary
- **Investment Tips**
  - Weekly articles and insights

### Footer
- Quick links
- Contact information
- Social media links
- Newsletter signup

## Design Principles

### Color Palette
- Primary: Deep blue (#1e3a8a) - trust and stability
- Secondary: Gold/Orange (#f59e0b) - prosperity and warmth
- Accent: Green (#10b981) - growth and success
- Neutral: Grays for text and backgrounds

### Typography
- Headings: Modern sans-serif (Inter or similar)
- Body text: Clean, readable font
- Emphasis on hierarchy and readability

### Visual Style
- Modern, professional, and trustworthy
- Clean layouts with plenty of white space
- High-quality images of Malaysian properties
- Interactive elements with smooth animations
- Mobile-first responsive design

### Key Features
- Interactive property search and filtering
- Responsive design for all devices
- Fast loading times
- SEO optimized
- Accessibility compliant
